# 원본과 신뢰 경계

* `../reports/*.json`이 검증 가능한 발행 원본입니다.
* 이 위키는 원본에서 파생되며 새로운 시장 주장의 독립 증거로 사용할 수 없습니다.
* `verified`가 `process:` 또는 에이전트로만 구성된 문서는 machine-confirmed입니다.
